# 카페 과거 기록 수집 지시서 (PC 클로드 + Aside 브라우저용, 한 번만)

kS ELO 사이트에 아직 안 들어간 과거 경기 기록을 네이버 카페에서 모아 저장소에 넣는 일이다.
카페 글 본문은 로그인해야 보이므로 **사장님 PC의 Aside 브라우저(네이버 로그인 상태)** 로 읽는다.
클라우드 클로드는 네이버 로그인을 못 해서 이 일을 PC 쪽에 맡긴다.

## 0. 준비
- 저장소: `https://github.com/lupi20000/ks-elo-platform` (main). 없으면 받아서(clone) 쓴다.
- 결과 파일 두 개만 만든다: `data/sources.json`, `data/elo_backfill.json` (+ 못 읽은 것 기록 `data/backfill_unresolved.json`)
- 다른 파일은 고치지 않는다. 시트에는 절대 쓰지 않는다. 실명은 어디에도 적지 않는다.
- 커밋은 경로를 지정해서(`git add data/sources.json data/elo_backfill.json data/backfill_unresolved.json`), 메시지는 한글.

## 1. 리그 시트 찾기 — 게시판 3곳
| 게시판 | 주소 | 내용 |
|---|---|---|
| 27 | https://cafe.naver.com/f-e/cafes/30800617/menus/27 | 프로리그 KPL |
| 29 | https://cafe.naver.com/f-e/cafes/30800617/menus/29 | 개인리그 KSL · KTL 등 |
| 47 | https://cafe.naver.com/f-e/cafes/30800617/menus/47 | 이벤트리그 |

- 각 게시판의 글 목록을 끝까지 넘기면서 **리그 제목 + 개요가 붙은 글**(리그 소개·공지 글)을 연다.
- 본문에서 **구글 시트 링크**(`docs.google.com/spreadsheets/d/...`)를 모두 찾는다. 시트 안에 경기결과가 있다.
- 시트마다 아래 한 줄을 `data/sources.json` 배열에 넣는다.

```json
{
  "id": "cafe27-123456-1",            // cafe<게시판>-<글번호>-<순번>  (영문·숫자·하이픈)
  "name": "KSL 시즌3 본선",            // 리그 이름 그대로
  "league": "KSL 본선",               // 아래 '리그 이름 표' 중 하나로 맞춘다
  "weight": 2.5,                      // 아래 표의 가중치
  "url": "https://docs.google.com/spreadsheets/d/.../edit#gid=...",  // 경기결과 탭이 열리는 링크(gid 포함)
  "enabled": true,
  "defaultDate": "2024-05-10",        // 시트에 날짜 칸이 없을 때 쓸 날짜 (아래 규칙)
  "board": 29, "articleId": 123456, "postTitle": "글 제목", "period": "2024-05-01 ~ 2024-05-31"
}
```

- **경기결과가 들어 있는 탭의 gid**를 링크에 꼭 붙인다. 탭이 여러 개면 경기결과 탭마다 한 줄씩.
  (시트를 열어 아래 탭을 눌렀을 때 주소창 `#gid=` 숫자)
- 시트가 비공개(로그인 요구)면 넣되 `"enabled": false`, `"note": "공유 꺼짐"` 을 붙인다.
- **날짜 규칙**: 시트에 날짜 칸이 있으면 `defaultDate` 는 그냥 리그 시작일. 날짜가 없으면 글에 적힌 리그 기간을 보고
  가운데쯤 날짜로 정한다. 기간도 없으면 글 작성일. (사장님 지시: 대충 기간을 정해 임의로 넣어도 됨)
- 맵이 없으면 비워 둔다(사이트에 '확인불가'로 나온다).
- 열(승자·패자·날짜) 위치는 적지 않아도 된다. 매일 새벽 빌드가 자동으로 짐작한다. 못 짐작하면 운영진 화면 '시트 등록'에 문제로 뜨고, 거기서 열을 고르면 된다.

## 2. ELO 결과입력 게시판 — 과거 글 전부
- 주소: https://cafe.naver.com/f-e/cafes/30800617/menus/71?viewType=W (글 900개 남짓)
- 글마다 본문을 읽고 **세트 단위**로 `data/elo_backfill.json` 배열에 넣는다.

```json
{ "date": "2025-08-14", "league": "ELO", "map": "폴리포이드", "winner": "rox", "loser": "Woo",
  "wrace": "T", "lrace": "T", "url": "https://cafe.naver.com/f-e/cafes/30800617/articles/123456" }
```

- 2:1 같은 다전제는 세트마다 한 줄. 세트별 승자를 모르면 이긴 세트 수만큼 승자→패자, 진 세트 수만큼 반대로 넣는다.
- 아이디는 **게임 아이디(영문)** 로. 한글 별명만 있고 누군지 모르겠으면 넣지 말고 `backfill_unresolved.json` 에
  `{ "url": ..., "title": ..., "why": "한글 별명 '○○' 신원 불명" }` 으로 남긴다.
- `[kS]` 같은 클랜 표기는 떼고 적는다. 종족을 모르면 빈 글자.
- 날짜는 경기 날짜, 없으면 글 작성일.

## 3. 끝나면
1. `python -c "import json;[json.load(open(p,encoding='utf-8')) for p in ['data/sources.json','data/elo_backfill.json']];print('ok')"` 로 형식 확인
2. 경로 지정 커밋 → `git push origin main`
3. 사장님께 한글로 보고: 찾은 시트 수(게시판별), ELO 세트 수, 못 읽은 글 수
4. 반영은 다음 날 새벽 자동 갱신 때. 바로 보고 싶으면 깃허브 Actions 의 **"매일 데이터 갱신" → Run workflow**.
